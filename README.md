# Portafolio Interactivo

Landing page desarrollada con Bootstrap 5 y CSS puro.

## Transformaciones aplicadas
- **rotate:** Caja 1 gira 10° al hacer hover.
- **scale:** Caja 2 se agranda 1.15 veces.
- **skew + translateY:** Caja 3 se inclina y sube.
- **3D:** Tarjeta con `perspective`, `preserve-3d`, `rotateX()` y `rotateY()`.

## Animaciones aplicadas
- `@keyframes deslizar`: el título entra deslizándose y cambia de color.
- `@keyframes girar`: loader circular infinito (en el hero y dentro del botón Enviar).
- Se usan `animation-duration`, `animation-iteration-count` y `animation-timing-function`.
